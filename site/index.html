What's actually real

Every claim below has a test in the repo that checks it — including negative tests that confirm tampering gets rejected, not just that the happy path works.

Interpreter + AIR

An accumulator machine with real conditional control flow (JZ/JNZ) and a 4-register file (LOAD/STORE). The AIR binds a proof to one specific program and which branch it took, which register it touched — not just "a valid trace exists."

STARK prover/verifier

Built on Winterfell. Sound without a lookup/permutation argument, because this system has no secret witness — the verifier already re-executes the program, so most trace columns are asserted directly instead of derived algebraically.

HTTP + MCP service

Push a .zkasm program, get a proof back — over HTTP, or straight from Claude Desktop / Cursor via a real MCP prove/verify tool pair, verified against an actual client handshake.

How it fits together

One path from source to proof to on-chain settlement — no step skipped, no box standing in for something unbuilt.

The discipline, in its own words

Pulled directly from this repo's own docs — not paraphrased, not softened.

"What's explicitly NOT here yet" — loops, addressable memory, RISC-V compatibility, formal verification, fuzzing, external audits, recursion, a second proving backend. Named individually, with why each is genuinely hard. docs/ROADMAP.md
"AttestedVerifier is a trusted bridge (an off-chain party attests a proof checked out), not a cryptographic verifier." Stated as the headline fact, not a footnote. docs/THREAT_MODEL.md
SP1 integration: "a real crate, a real API" — investigated, then declined, with the actual reasons (518 dependencies for a hello-world, a Go FFI dependency, a 4-minute failing cargo check) written down instead of quietly dropped. docs/HOST_SERVICE.md

Try it

Three ways in — pick whichever fits.

# run the full execute -> prove -> verify -> tamper-check demo
$ cargo run --release -p zkvm-cli -- demo

# or "push code, get a proof" over HTTP
$ cargo run --release -p zkvm-host-server &
$ cargo run --release -p zkvm-cli -- deploy examples/fibonacci_like.zkasm

# or from Claude Desktop / Cursor over MCP
$ cargo build --release -p zkvm-host-server && ./scripts/mcp_demo.sh
