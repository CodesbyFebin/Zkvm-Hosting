AIR design

Execution trace

A table recording the full state of a machine at every step of a computation — one row per step, one column per piece of state. The AIR's constraints are checked against this table.

In this repo: one row per static instruction (not per executed step — a skipped branch still gets a row with active = 0), 10 fixed columns plus two per register. Produced by zkvm_isa::execute.
Related terms: AIR, Transition constraint, Boundary constraint
