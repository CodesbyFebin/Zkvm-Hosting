Proof system

FRI

Fast Reed-Solomon Interactive Oracle Proof of Proximity

The low-degree testing protocol that lets a STARK prover convince a verifier that a committed polynomial really is close to low-degree, without the verifier evaluating it everywhere. It's the piece that makes STARKs “scalable” and avoids a trusted setup.

In this repo: handled entirely inside Winterfell — this project doesn't implement FRI itself, it configures and calls Winterfell's implementation via ProofOptions in zkvm-stark.
Related terms: STARK, Winterfell
