On-chain

Attestation

In this context: a signed statement from a designated party that something is true, used as a (trusted, not cryptographic) stand-in for a check that isn't otherwise implemented. Different from a proof — an attestation asks you to trust who's speaking, a proof doesn't.

In this repo: AttestedVerifier.sol accepts a proof once a designated attester address calls attest(...) — an explicit trust bridge, not a cryptographic on-chain check. See The Trust Boundary, Written Down.
Related terms: SNARK, Verifier
